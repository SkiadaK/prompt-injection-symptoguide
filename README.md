# SymptoGuide: άσκηση prompt injection

Το SymptoGuide είναι ένα chatbot προσανατολισμού σε ιατρικές ειδικότητες, υλοποιημένο με Python, Gradio, LiteLLM και Ollama.

Ο χρήστης περιγράφει μια ενόχληση ή ένα σύμπτωμα και το σύστημα προτείνει την κατάλληλη ιατρική ειδικότητα, χωρίς να παρέχει διάγνωση, θεραπεία ή φαρμακευτικές οδηγίες.

Η εφαρμογή αναπτύχθηκε στο πλαίσιο του σεμιναρίου **"AI for Developers: Design, Build, Deploy LLM-powered Applications"** του **Οικονομικού Πανεπιστημίου Αθηνών (ΟΠΑ)**.

## Χαρακτηριστικά

- Καθοδήγηση προς κατάλληλη ιατρική ειδικότητα
- Προστασία από prompt injection επιθέσεις
- Φίλτρα εισόδου και εξόδου (input/output guards)
- Ανίχνευση επειγόντων περιστατικών
- Ελληνική γλώσσα
- Τοπικό LLM μέσω Ollama (Gemma 3 4B)
- Web διεπαφή μέσω Gradio

## Προαπαιτούμενα

- Python 3.14+
- Ollama

## Εγκατάσταση

```bash
pip install -r requirements.txt
```

## Λήψη μοντέλου

```bash
ollama pull gemma3:4b
```

## Αρχείο .env

```env
MODEL_LOCAL=ollama_chat/gemma3:4b
GUARDS=1
```

## Εκτέλεση

```bash
python sympto_web.py
```

Με την εκτέλεση της εφαρμογής δημιουργείται αυτόματα:

- Τοπικό URL (localhost)
- Δημόσιο Gradio share link

μέσω των οποίων η εφαρμογή μπορεί να χρησιμοποιηθεί από browser.

## Δοκιμές ασφαλείας

Κατά την ανάπτυξη πραγματοποιήθηκαν δοκιμές prompt injection με στόχο την παράκαμψη των κανόνων του συστήματος και την εξαγωγή απαντήσεων που περιέχουν διάγνωση ή φαρμακευτικές οδηγίες. Τα ευρήματα χρησιμοποιήθηκαν για την ενίσχυση των μηχανισμών προστασίας του chatbot.
